# Pet Salon by Marcio Rodrigo

Site institucional responsivo em HTML, CSS e JavaScript. Abra `index.html` no navegador ou sirva esta pasta em um servidor estático.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: sistema visual e responsividade.
- `script.js`: navegação móvel, abas, filtros, avaliações e links de WhatsApp.
- `img/`: fotos entregues para o projeto e imagem editorial gerada para o hero.
- `documentos/paleta-e-direcao-visual.md`: cores, tipografia, uso de imagens e pendências de validação.
